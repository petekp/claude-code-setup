# Reporting research

Lead with the answer or recommendation. Explain the evidence and tradeoffs that determine it. Use a table when readers need to compare the same dimensions across options.

Keep factual claims, source interpretations, and your own inferences distinct. Cite the source that directly supports each material claim. Convey sources in your own words; use only short, marked quotes when exact wording matters. Group a comparison around agreement and disagreement, not a sequence of article summaries.

Include uncertainty where it changes the conclusion. Name any remaining question, unavailable source, mismatched version, or untested condition that limits the advice. Avoid unsupported confidence percentages and formulaic source-count ratings.

For a substantial artifact, include a compact record of the scope, source dates or versions, evaluation criteria, and gaps. Add a source-quality table or search appendix only when the user needs to audit the research. Omit empty sections and conclusions already stated.
