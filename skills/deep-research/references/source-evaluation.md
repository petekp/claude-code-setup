# Source evaluation

Judge evidence against the claim it must support. A domain suffix, citation count, polished page, or number of agreeing articles is not proof of accuracy. Several articles repeating one report are one underlying source.

For documentation, check the product, version, date, and conditions. Official documentation supports what a vendor specifies; it does not by itself establish comparative performance or an independent safety assessment. For local behavior, compare it with the installed code or observed result.

For empirical research, inspect the method, sample, comparison baseline, uncertainty, and limits on generalization. For AI benchmarks, include model version, tools, prompts, reasoning settings, and evaluation conditions when they affect the claim. Separate measured outcomes from proposed explanations.

For conflicting sources, check whether they describe different dates, populations, definitions, or conditions before treating them as a disagreement. Trace secondary accounts to original evidence. Report unresolved contradictions with both citations.

Use confidence labels when they help the decision, and explain the basis. An explicit primary record can support high confidence for a narrow fact. Several weak or dependent sources cannot. An unsuccessful search establishes a coverage gap, not that the evidence or event does not exist.
